## Design review and bounded change

The selected technical route is direct Mod session context summary, confidence **0.82**: the official type spells the API and completeness counters, but real installed Desktop behavior and the type/validator version match remain untested. A preflight only from `$.tool.list()` would be false evidence: the `Skill` tool is an invocation entry point, not names. An alternative of leaving Claude unknown has confidence **0.62** as a safe no-code route but fails to use the documented native read API. No host-wide success is inferred from source tests; if the native summary omits data in the real host, the operation reports the gap and must be reassessed, not retried through Agent prompts.
